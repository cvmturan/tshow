Quick answers

Frequently asked questions

Why does a title show no playable source?

TShow provides discovery and trailers. Playback depends on the sources returned by add-ons you choose to install.

Are my add-ons shared with other users?

No. Their addresses are stored in this browser and restored only for this browser. Clearing site data removes them.

Can an add-on run code on my device?

TShow reads validated JSON responses. It does not insert add-on HTML or JavaScript into the page, and unsafe protocols are blocked.

How do I install TShow?

Use “Install app” in the menu. On iPhone, open the site in Safari, tap Share, then Add to Home Screen.
