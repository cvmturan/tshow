# TShow Desktop third-party notices

TShow Desktop includes an unmodified Windows build of mpv for device-local media
playback. mpv is free and open-source software maintained independently from
TShow.

- Project: https://mpv.io/
- Source: https://github.com/mpv-player/mpv
- Windows build source and scripts: https://github.com/shinchiro/mpv-winbuild-cmake
- Bundled build: `mpv-x86_64-20260903-git-69e63f425a.7z`
- License information: https://github.com/mpv-player/mpv/blob/master/Copyright

The playback engine connects directly from the user's device to the selected
provider. TShow's web server does not proxy, cache, download, or transcode the
media.
